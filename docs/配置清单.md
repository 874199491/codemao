# 其他老师配置清单

发给其他老师前，让对方准备这些信息：

1. 钉钉学情表链接，或云文档 node_id。
2. 学情表所在 sheet 的 ID，通常形如 `st-xxxxxx-xxxxxx`。
3. CRM 账号登录权限。
4. CRM 班级 ID 和班级标签，例如：
   - `CRM班级ID / 周五晚 / 周五`
   - `CRM班级ID / 周六午 / 周六午`
   - `CRM班级ID / 周六晚 / 周六晚`
5. 退费学员名单，如果需要剔除退费学员。
6. 本班开班日期。工作台默认按“周四到周一”为一个反馈周期。

配置完成后的验证顺序：

1. 看板运行环境显示 CRM 已登录。
2. `/api/config` 中显示目标老师自己的 `node_id`、`learning_sheet_id` 和班级 ID。
3. 状态检查能正常读取学员数量。
4. 抽查学情表不会出现上一个老师的数据。
