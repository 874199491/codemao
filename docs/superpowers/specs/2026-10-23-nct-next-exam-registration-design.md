# 年卡信息：下一级考级报名等级

## 目标

在工作台的 NCT 考级（年卡信息）中，记录学生已报名的下一级考级等级，并能在学情表中直接查看。

## 数据字段

- 字段名：`已报名下一级考级`
- 格式：可编辑文本，填写实际等级，例如“一级”或“二级”。
- 空白表示尚未报名。

## 数据位置与同步

1. 在 `NCT考级` 表中新增该列，作为老师手工维护的字段。
2. 在学情表中新增同名列，并按学生 ID 同步该文本。
3. “更新 NCT 考级”任务继续从 CRM 刷新年卡、历史考试和推荐等级；不得覆盖这列手工填写的数据。
4. 新出现的学生默认留空。

## 边界

- `下一次推荐报考等级` 是系统建议，不等同于已经报名。
- 不从 CRM 推断或写入“已报名下一级考级”，避免将建议或旧报名状态误记为实际报名。
- 同步以学生 ID 为准，未匹配的记录跳过并保留现有表格内容。

## 验证

1. 首次运行后，两张表均存在同名列。
2. 手工填写等级后再次运行更新任务，NCT 考级表内容保持不变。
3. 学情表中对应学生显示相同等级；空白学生仍为空。
