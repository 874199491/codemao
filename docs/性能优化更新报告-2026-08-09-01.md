# 看板性能优化更新报告（2026-08-09-01）

## 本次优化

为学情统计增加“按数据文件修改时间失效”的进程内缓存。看板重复刷新时，不再反复读取完课缓存、学员名单、退费名单并重新计算全部学员分组；任一相关文件发生变化后会自动重新计算。

## 涉及功能

- 工作台首页 `/api/summary`
- 首页刷新看板
- 学员状态卡片和异常学员明细

## 数据安全

缓存只存在当前 Python 进程内，不写入学生数据文件，也不改变钉钉表格内容。配置、完课缓存、名单或退费文件变化后会自动失效。

## 验证

- 个人版和副本版 `server.py` 均通过 Python 3.10 语法检查。
- 已保留外部数据更新流程不变。
- 本地重复请求实测：个人端首页统计约从 219ms 降至 60–75ms；副本端受 CRM 登录探测影响约 0.6 秒，但学员分组计算不再重复执行。
- 当前识别到的下一项候选是每周趋势接口的多周缓存复用。
- 下一步可继续优化每周趋势接口的多周重复计算。
