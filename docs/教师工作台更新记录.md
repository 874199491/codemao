# 教师工作台更新记录

钉钉持续更新文档：[教师工作台更新记录](https://alidocs.dingtalk.com/i/nodes/ZgpG2NdyVXrAYQbpIPpprraZ8MwvDqPk)

## 2026-08-09

### 看板与运行环境

- 新增“刷新看板”按钮，可重启当前工作台服务并加载磁盘上的最新代码。
- 重启前检测正在执行的任务。
- 任务列表加载增加短暂重试和并发复用。
- 看板支持按周选择更新，并增加每周趋势页面和图表展示。
- 定时任务独立页面支持新建、编辑、启停、删除、立即执行和拖动排序。

### 学情与数据更新

- 完课、直播、接龙、邀约跟进、课后反馈均按周区分。
- 接龙更新改为增量勾选，使用复选框格式并在写入后回读校验。
- 学生时间段更新会剔除退费学员，并按“周五晚、周六午、周六晚”排序。
- 课后反馈支持周测、课中习题、笔记、错题订正、评分阈值、知识点和结尾话术配置。
- 旧周反馈配置默认收起，当前最新周默认展开。

### 配置与复用

- 支持从其他老师的 CRM 登录和钉钉学情表生成配置。
- 支持表头探测、GitHub 更新和本地配置保留。
- 副本不携带个人学生数据、Cookie 和运行缓存。

### 交互与界面

- 学员明细支持按姓名、学生 ID 和上课时间筛选。
- 复制学生 ID 时只复制当前筛选结果。
- 配置弹窗、定时任务页面、周反馈配置和学员明细完成布局调整。

以后每完成一项功能或规则调整，在本页和钉钉文档末尾追加日期、改动内容、影响页面和验证结果。

## 2026-08-10

### 课后反馈规则

- 修复“课后作业订正提醒”误用课中习题正确率的问题。
- 订正提醒不再根据“课中习题正确数/总数”触发，避免周测 100% 正确但课中习题非满分的学员被误提醒课后作业订正。
- 新规则只在反馈数据中明确存在“课后作业错题数/错误数/需订正数/订正数”、或“课后作业正确数/总数”、或“课后作业正确率低于 100%”时触发订正提醒。
- 已同步个人看板和教师工作台副本模板。
- 验证结果：周测 100% 且仅课中习题非满分时不再追加订正提醒；明确存在课后作业错题时仍会追加配置中的订正话术。

## 2026-08-21

### 大班学情表完整读取

- 修复学情表周次较多后，宽范围读取触发钉钉单次单元格数量限制，导致表格后半段学生被遗漏的问题。
- 接龙更新改为只读取学生 ID、姓名、上课时间和当周接龙列；W5 周六实测从错误识别 71 行恢复为完整识别 132 行，并补齐 31 个漏记复选框。
- 新增通用分块读取能力：完课、直播、学生时间段、邀约跟进、补课表、课后学情反馈、反馈发送状态、取消反馈状态和 NCT 考级均会分块读取大范围数据，同时保持原表行号不变。
- 验证结果：个人学情表完整返回 300 行范围、223 个有效学生；W5 接龙写入后周六共校验 77 个已勾选，完课只检查模式完整识别周五晚 91、周六午 32、周六晚 100 个有效学员。

### CRM 完课接口并发失败恢复

- CRM 多班并发抓取出现 HTTP 500 后，会自动对失败班级执行最多两次串行重试，降低接口瞬时限流导致整批任务失败的概率。
- 串行重试仍失败时，仅对已经结束的历史周启用缓存兜底；必须逐班校验目标两课均覆盖全部缓存学员，才允许继续写入。
- 当前周、未来周、缺少班级、缺少目标课或存在“无数据”的缓存仍会停止，避免使用旧数据误写钉钉。

### 每期固定三个授课班

- 固定每位老师每一期只处理三个授课班：周五、周六午、周六晚。
- 更新前会校验配置恰好包含三个不同班级 ID，且三个上课时间各出现一次；配置不符合时提前停止并提示重新生成配置。
- 完课班级 CSV 会按当前老师配置自动整理，只保留这三个班并按配置顺序排列；旧班、其他班期和重复班级不再参与 CRM 抓取。

## 2026-08-27

### 赛考集训课不计入完课统计

- 看板配置新增“该课线包含赛考集训课”开关；个人进阶科特班配置已启用，教师副本默认关闭。
- 开启后，第 11、21、31、41、51……课会被视为额外集训课，不计入每周完课、补课判定、课后反馈或月度绩效。
- 周次课程会自动顺延，例如 W5 为第 9、10 课，W6 为第 12、13 课，不需要老师手动调整课号。
- CRM 明细仍保留集训课原始记录用于核对，但汇总完课节数和完课率会排除这些课。
- 已同步个人工作台和教师工作台副本；Python、JavaScript 语法检查通过，课号映射已覆盖第 11、21、31、41、51 课。

## 2026-08-28

### 月考反馈页面排版

- 个人工作台的月考反馈页重排为顶部命令栏、三段流程提示、左侧反馈配置、右侧逐个核对队列的结构。
- 配置区保留月考文件夹、成绩文件、学员名单、教师称呼、错题报告和奖状开关、五档话术编辑。
- 预览区强化成绩记录、可发送、需处理、已选择四个关键状态，并优化筛选栏、表格、附件状态和发送操作区。
- 月考页样式选择器已收窄到当前页面，避免影响定时任务、趋势、绩效等其他页面。
- 验证结果：`monthly-exam.js` 语法检查通过，`server.py` 和月考脚本编译通过，页面接口 `/api/monthly-exam` 可正常返回真实预览数据，Impeccable 机械检测无问题。

### 月考反馈筛选与发送标记

- 成绩档位筛选从单选改为多选，可同时查看多个分数段学员。
- 月考反馈结果区新增“已发送”状态；本地结果文件中明确 `created: true` 的学员，会在当前成绩文件下标记为已发送。
- 已发送学员默认不再参与“选择当前结果”和“一键发送全部可发送”，接口侧也会跳过已发送学员，降低重复创建企微待发送任务的风险。
- 已发送匹配会校验学生 ID、姓名/分数和当前成绩文件，避免旧月考结果误标新月考。

### 月考反馈保护展示分

- 月考反馈页新增“生成保护展示分”按钮，点击并确认后，只更新当前预览清单和反馈话术中的展示分。
- 保护展示分规则：原始成绩低于 50 展示为 60，50-59 展示为 65，70 或 75 展示为 80。
- 原始成绩 Excel、题目得分、错题报告 PDF 和奖状文件不会被修改；页面会显示“原始分 → 展示分”用于人工核对。
- 月考反馈本地发送结果已清空：`data/monthly-exam-feedback/results` 当前没有学生结果，`sent-status.json` 已删除。

### 月考反馈话术口语化

- 重写月考反馈五档话术，整体改为更口语化、鼓励型表达。
- 新话术保留学生姓名、分数、错题题号、教师称呼等变量，不影响后续预览和发送。
- 已重新生成当前月考预览，确认中文内容和变量替换正常。

### 月考错题报告生成规则

- 工作台生成错题报告时会跳过 0 分和 100 分学员；保护展示分开启时，也会同时检查原始分和展示分，避免原始 0 分被展示成 60 后误生成错题报告。
- 奖状规则保持不变：展示分达到 80 分及以上才生成奖状。

### 月考成绩表表头兼容

- 月考反馈预览的成绩表识别从固定列名扩展为“别名 + 关键词”识别，兼容“学生编号 / 孩子名称 / 本次得分 / 总成绩 / Q1 / 1题得分”等表头。
- 表头定位失败时会输出缺失字段和最接近的表头行，便于老师判断是成绩文件选错还是表格格式不匹配。
- Python stderr 改为 UTF-8 输出，减少老师电脑上报错变成乱码的问题。

### 月考反馈企微家长映射

- 月考反馈发送不再要求每个学生只有一个企微家长映射；同一学生存在多个可发送家长时，会合并去重后继续创建待发送任务。
- 仅在完全没有可发送企微家长映射时停止，避免无接收人任务。

## 2026-08-29

### 运行环境安装器兼容

- 一键安装运行环境改为先检查老师电脑上已有的 Python 3.10+、Node.js 18+ 和 npm，满足要求时直接复用，不再重复安装。
- Python 检测会跳过 `.venv` 等虚拟环境，避免把依赖装进其他项目导致工作台仍然缺包。
- 启动脚本支持 Python 3.10、3.11、3.12、3.13、3.14，不再固定依赖 `py -3.10`。
- 工作台后续执行 Python 子脚本时，会沿用启动工作台的同一个 Python，减少“安装成功但运行仍缺包”的情况。
- 一键安装会补齐月考反馈所需依赖：`requests`、`fpdf2`、`python-pptx`、`pywin32`、`pywinpty`。
- 安装依赖时增加空包名保护和 PowerShell 原生命令错误兼容，避免 `pip install` 因空 requirement 或 stderr 输出直接中断。
- 验证结果：本机已有 Python 3.10.11、Node v24.14.1、npm 11.11.0 时，安装器未触发 Python/Node 重装，仅检查并跳过已安装依赖。

### 月考错题报告隐私

- 错题报告 PDF 去除“本次得分”展示行，只保留学生姓名、需重点回顾题号和题目讲解图。
- 已同步个人工作台和教师工作台副本；后续重新生成错题报告时不会再在 PDF 中展示成绩。
- 错题报告 PDF 同步去除“共需几道题”汇总行，避免家长第一眼只看到错题数量。

### 月考反馈取消与奖状阈值

- 月考反馈配置新增“奖状分数阈值”，默认 80 分；开启保护展示分时按展示分判断是否生成/发送奖状。
- 月考反馈页新增“取消已选月考反馈”按钮：已发送学员也可被勾选，取消按钮只处理已发送学员，发送按钮仍只处理可发送学员。
- 取消逻辑只扫描当前配置班级内的月考反馈任务，不会取消其它普通群发。
- CRM 取消成功后，会同步清除本地 `sent-status.json` 和对应 result 文件的已发送标记，使该学员回到“可发送”。
- 如果企微客户端已经确认发送，CRM 会拒绝取消；这类学员不会自动回退为可发送，避免重复发送给家长。
