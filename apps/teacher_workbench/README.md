# 教师工作台

本地网页控制台，用固定按钮调用已验证的 0724 周度更新与课后反馈脚本。

## 启动

双击桌面的 `启动教师工作台.bat`，或运行：

```powershell
py -3.10 apps\teacher_workbench\server.py
```

默认地址：`http://127.0.0.1:8765`

如果服务已经启动，再次双击桌面入口只会打开现有页面，不会重复启动。

## 当前按钮

- 检查运行状态
- 更新最新周完课数据
- 更新最新周直播数据
- 同时更新最新周完课和直播
- 更新最新周课后学情反馈
- 从已完课名单发送最新周课后反馈

周次以 `2026-07-24` 为 W1 起点，每 7 天自动递增。W1 对应第 1、2 课，W2 对应第 3、4 课，依此类推。页面会显示本次目标周、日期范围和课程编号。

首页实时展示 0724 总学员、未到课、第一课未完课、到课未完课和已完课人数及占比。
点击任一指标卡片可查看对应学生姓名、学生 ID、上课时间和班级，并可复制全部 ID。

## 安全规则

- 只能调用服务端白名单中的固定任务，网页不能提交任意命令。
- 一次只运行一个任务。
- 写入钉钉的操作必须二次确认。
- 不同周使用独立的反馈状态；新一周不会继承上一周的“是否已反馈”勾选。
- 课程 ID 从 CRM 当前课程记录中解析，不按数字顺序猜测。
- 服务只监听 `127.0.0.1`，不向局域网或互联网开放。
- 页面关闭不会终止正在运行的任务；重新打开页面可以继续查看日志。
